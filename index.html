Sobre mí

Soy Hugo Olazabal y estudio Ingeniería en Computación en la Facultad de Ingeniería de la Udelar. En 2024 empecé HmobProds, mi emprendimiento de diseño 3D y fabricación aditiva: modelo las piezas, las imprimo y atiendo a cada cliente de forma directa.

Esta web también es un proyecto de programación. La estoy construyendo desde cero, con HTML, CSS y JavaScript y sin frameworks, para aprender cómo funciona cada parte. El código está en GitHub.
